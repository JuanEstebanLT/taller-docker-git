# Flujo de Trabajo Git

## Ver ramas

git branch

git branch -a

## Crear una rama

git checkout -b nombre-rama

## Ver estado

git status

## Agregar cambios

git add .

## Crear commit

git commit -m "tipo: descripcion"

## Ver historial

git log --oneline --graph

## Descargar cambios

git pull origin main

## Subir una rama

git push origin nombre-rama

## Fusionar una rama

git checkout main

git merge nombre-rama

## Eliminar una rama

git branch -d nombre-rama
